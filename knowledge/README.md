# 이음 안내 자료 (RAG 문서)

안내 Agent가 답할 때 찾아 읽는 문서입니다. `rag.py`가 `## 제목` 단위로 잘라(조각) 검색합니다.

- 파일 맨 위 `---` 사이에 제목(title)과 출처(source)를 적습니다. 출처는 답변 아래에 그대로 보입니다.
- 모든 문서는 **데모용 요약**입니다. 진료지침 원문을 옮기지 않고 일반인이 읽는 말로 다시 썼습니다.
- 실제 운영 전에는 이식센터 의료진이 문서마다 검토하고 `reviewed`를 바꿔야 합니다.
- 문서를 고치면 `python eval/run_eval.py`로 검색 평가(eval/rag_cases.csv)가 떨어지지 않는지 확인합니다.
