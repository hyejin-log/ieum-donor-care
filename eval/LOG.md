# 안내 Agent 실패 기록

에이전트가 "어느 길로 답할지"(응급 / 안내문 / 내 기록 / 일반 대화 / 마음 상담 / LLM) 고르는 단계를 질문 세트로 평가하고,
틀린 것을 원인별로 고친 기록입니다. 실행: `python eval/run_eval.py` → `eval/report.md`

## 1회차 · 개발용 42문항: 86% (36/42), 응급 재현율 10/10, 오경보 2건

| 틀린 질문 | 정답 → 실제 | 원인 | 고친 방법 |
|---|---|---|---|
| 내 크레아티닌 수치 어때요? · 내 eGFR 수치 알려 주세요 | 내 기록 → 안내문 | 검사 이름만 보고 '용어 설명' 안내문으로 보냄 | "내·제·수치·결과"가 있고 "뭐예요"가 없으면 용어 설명이 아니라 내 값 조회로 |
| 이번 주에 기록했나요? · 다른 기증자들은 어떻게 지내요? | 내 기록 / LLM → 일반 대화 | 문장 분류 모델이 '일반'으로 보면 묻는 말이어도 "알려 주셔서 고마워요"로 답함 | 묻는 말(?, 나요, 어떻게…)이면서 인사·감사가 아니면 일반 대화로 답하지 않음 |
| 기증 후 보험 가입에 불리한가요? | LLM → 응급(119) | 문장 분류 모델이 응급 0.92로 과신 | 모델만 응급이라 하고 **몸의 증상 단어가 하나도 없으면** 오경보로 처리. 응급 문항 재현율은 그대로인지 함께 확인 |
| 요즘 우울하고 잠이 잘 안 와요 | 마음 상담 → 응급(119) | 마음이 힘든 말에 119·응급실 안내는 맞지 않음 | '마음 상담' 길을 새로 만듦: 심리 상담 연결 + 109(자살예방 상담전화). "죽고 싶다" 같은 말은 응급 길에서 109를 먼저 안내 |

## 2회차 · 개발용 50문항(새 문항 8개 추가): 96% → 100%

새로 넣은 응급 문항 "배가 너무 아파서 움직일 수가 없어요"를 놓침 (모델 응급 확률 0.25). 응급 단어에 "움직일 수가 없", "참을 수 없"을 추가.
"여행 가서 혈압계를 못 챙기면 어떡해요?"가 '혈압' 단어 때문에 내 기록 조회로 감 → "어떡·혈압계"는 제외.

## 3회차 · 확인용 20문항 (고칠 때 보지 않은 질문): 75% (15/20), 응급 재현율 4/5

개발용이 100%여도 **새 질문에서는 75%** — 규칙을 '외운' 부분이 있다는 뜻입니다.

- 놓친 응급: "얼굴 한쪽이 처지고 말이 어눌해요"(뇌졸중 의심). 안전 문제라 확인용이어도 바로 고침 → 응급 단어 추가
- 내 기록을 못 알아들음: "다음 병원 검사가 언제죠?", "제 eGFR 몇이에요?" → 단어 하나씩 더하지 않고 규칙을 일반화 ("검사" + "언제/며칠", 검사 이름 + "내/제/몇/얼마")
- **일부러 고치지 않음**: "아무것도 하기 싫고 다 그만두고 싶어요", "요즘 밤에 자꾸 깨요" → 마음 상담으로 가야 하지만 단어 목록으로는 끝이 없음. 지금은 LLM이 답함

고친 뒤 확인용 90% (18/20), 응급 재현율 5/5. 단, 이 확인용 세트는 이제 한 번 본 세트라 다음에는 새 확인용 세트가 필요합니다.

## 배운 점과 다음 할 일

- 의료처럼 놓치면 안 되는 길(응급)은 **단어 규칙 + 모델 둘 중 하나라도** 잡게 두고, 모델의 오경보는 규칙(증상 단어 유무)으로 거른다.
- 규칙은 빠르고 설명하기 쉽지만 새 표현에 약하다(확인용 75%). 다음에는 문장 분류 모델을 이 실패 문장들로 다시 학습하거나,
  LLM에게 길 고르기를 맡기고 결과를 이 평가 세트로 비교할 계획.
- 지금은 '길 고르기'만 평가한다. LLM이 쓴 답의 내용(근거를 지켰는지, 단정 표현을 했는지)은 다음 단계로 추적 도구(Langfuse 등)를 붙여 평가할 예정.
